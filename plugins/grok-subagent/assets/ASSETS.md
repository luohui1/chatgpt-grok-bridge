# Project identity

`bridge-mark.png` is an original identity created for ChatGPT Grok Bridge.
Two gateway-like forms joined by a bridge represent communication between
an assistant and a locally owned agent.

Palette: charcoal, white and mint. The mark is intended to work at small sizes
in a README masthead and plugin listing.

Created using OpenAI's built-in image-generation tool. This is not OpenAI,
ChatGPT, Grok or xAI official artwork and does not imply affiliation or endorsement.
The project distributes this asset under its MIT license to the extent applicable;
no trademark-clearance claim is made.

## Generation brief

Original square app mark, no text: two white bracket-like gateway pylons connected
by a vivid mint elevated bridge span, centered on a flat charcoal background.
Simple, precise, strong small-size silhouette. No official brand marks, no knot,
no slash-orb, no gradients, shadows, mockups, robots or decorative circuitry.
